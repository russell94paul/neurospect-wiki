# The Unified Learning Path

The single sequenced route from "I understand the concepts" to "I'm cleared to live-trade" — built over
the [[concepts/mastery/unified/README|Unified Playbook]] (the *what and the decisions*) and graded on the
**existing** ladder / confidence / gate defined in [[concepts/mastery/README]]. This is the one ordered
spine; the two per-track paths ([[concepts/mastery/aura/learning-path]] and
[[concepts/course/README]]) are **folded in by reference**, not restated.

> **No-drift.** This page states the *order, the drills to run, and the exit bar per stage*. It does not
> re-explain any concept (the `unified/README` layers + the canonical `ict-*`/`aura-*`/`course/*`/
> `entry-models/*` pages own that) and it does not re-author any drill (the two exercise libraries own
> those). Everything here is a **link + a grade**. If a stage needs a concept or drill the wiki lacks, it
> is **flagged as a gap**, never invented.

## How this path is graded (reuse, do not restate)

All scales are defined once in [[concepts/mastery/README]] and reused here:

- **Ladder:** `1 Learned` → `2 Can-mark` → `3 Backtested` → `4 Live-ready`.
- **Confidence:** `1` no feel · `2` shaky · `3` usually right · `4` reliable · `5` automatic.
- **Rep counters** are a *floor*; the ladder stage is what gates readiness.
- The **Readiness-to-Live Gate** ([[concepts/mastery/README]] §Gate) certifies sim→live. **Hand-marking
  first, tools second** at every marking stage.

"**Graded**" here means: each concept below carries its **ladder-stage exit bar** and **rep target**, and
the stages are ordered so **an earlier stage gates the next** — you do not open U2 until U1's primitives
are at Can-mark, and the frontier stage (U5) does not open until the primitives + SMT stack (U1–U2) are solid.

> **Don't skip ahead.** This mirrors both mentors' own insistence on order (Aura: swing points → ranges →
> gaps → SMT; AXL: Module 1 → 5). The frontier content (U5) is *deliberately last* — it is a set of extra
> filters on setups you can already read and confirm, not a shortcut past them.

## The unified track vs. the two per-model tracks

This path is **model-agnostic**: it sequences the reconciled skeleton both mentors share. Where a stage's
drills live in one track's library, that is because that track authored the best drill for the shared
concept — the link is to the drill, not to the model's vocabulary. Run this unified path **or** run one
model's own path end-to-end; do not run three trackers in parallel. Log progress in
[[concepts/mastery/unified/tracker]].

## Stage U0 — Psychology & discipline (foundation)  · Playbook Layer 0

Ruling **R8** (psychology-first): both mentors put psychology and rules *ahead of* the model. Build this
first and keep it running under every later stage. Behavioural — no rep target, a held-habit gate.

- **Concepts** → [[concepts/mastery/unified/README]] Layer 0: [[concepts/aura/psychology-foundations]] ·
  [[concepts/aura/mind-and-emotional-control]] · [[concepts/aura/discipline-systems]] ·
  [[concepts/aura/journaling-system]] · [[concepts/business-logic/ict-live-commentary]] §Live Trading Discipline.
- **Drills (run both tracks' Stage 0 — they are complementary, not duplicative):**
  - Identity / four-killers / circuit-breakers / routine / journal → aura **D0-a…e** ([[concepts/mastery/aura/exercises]] §Stage 0).
  - Loss-limit precommitment, set-and-forget contract, three-requirements self-audit, bad-conditions log →
    ict-course **D0-a…e** ([[concepts/mastery/ict-course/exercises]] §Stage 0).
  - *(The two discipline canons are reconciled in [[concepts/mastery/unified/divergence-rulings]] R5 —
    the %/R blueprint is the framework; AXL's fixed-dollar cap is its prop-account special case.)*
- **Exit bar (ladder = behavioural gate):** pre-market routine + written circuit-breakers **actually
  followed for one week**; journal live and logging every trade incl. misses. Hard prerequisite for touching
  size at any later stage.

## Stage U2 — Confirmation: the nested SMT stack ⭐  · Playbook Layer 2

The centrepiece and the reconciliation's key synthesis (**R1**): SMT used **twice, at two altitudes**, and
their agreement is the strongest signal in the model. Do not open U2 until U1 is at Can-mark.

- **U2.1 Triads & asset selection (validated, not guessed)** → [[concepts/aura/triads-asset-selection]] ·
  drill aura **D2-a** (Pearson on daily returns). *Exit:* Learned→Can-mark · 1 triad computed + spot-check.
- **U2.2 Same-TF triad SMT — the LTF entry trigger** → [[concepts/business-logic/ict-smt]] §The Triad ·
  drill ict-course **D5-b** (multi-pane NQ+ES+YM, 5 days). *Exit:* Can-mark · cracking correlation spotted at the manipulation leg.
- **U2.3 Sequential SMT — the HTF structural anchor** → [[concepts/aura/sequential-smt]] · drill aura
  **D2-c** (NY-open drill + range flip, ~50). *Exit:* Can-mark · can state a swing's SMT-qualification and cycles **before** the indicator.
- **U2.4 The nested SMT stack (R1) + Sequential Skip** → [[concepts/mastery/unified/README]] Layer 2 ·
  [[concepts/mastery/unified/divergence-rulings]] R1 · drill aura **D2-d** (Skip). *Exit:* Can-mark · can identify a same-TF triad SMT sitting *inside* a confirmed higher-cycle Sequential SMT (the confluence to wait for).
- **U2.5 Aura Asset (6S) — optional 4th SMT leg (R7)** → [[concepts/aura/aura-asset]] · drill aura
  **D2-b** (≥20 weekly overlays). *Exit:* Learned→Can-mark · adopt the quantitative case, ignore the origin story.

- **Stage gate:** Sequential SMT + triad SMT at **Can-mark**, conf ≥3; you can build the nested stack read
  by hand before checking the indicator.

## Stage U3 — Execution (time → entry → levels)  · Playbook Layer 3

Once U1–U2 align, execute with the [[concepts/entry-models/README|entry-model library]]. **Time filters
gate the entry**; ruling **R4**: default to FVG/iFVG entries, reach for the richer PDA set only when the
structure calls for it.

- **U3.1 Time filter & day-of-week** (session/killzones; Tuesday highest; pre-NFP Thursday off-limits) →

  drills ict-course **D3-b** (kill zones, 1 wk), **D3-c** (deviations, 10 d), **D3-d** (daily bias, 10 d).
  *Exit:* Can-mark · bias written pre-session 10 days; only takes setups inside a valid window.
- **U3.2 Entry models (pick the one the structure matches)** — checklists are canonical in the YAML
  (**never fork**; the AI coach consumes them):
  - Consolidation → [[concepts/entry-models/consolidation-model]] · drill ict-course **D2-b**
  - Expansion/retracement → [[concepts/entry-models/expansion-retracement-model]] · drill **D2-c**
  - Reversal / raid-on-stops → [[concepts/entry-models/reversal-raid-on-stops]] · drill **D2-d**
  - London → [[concepts/entry-models/london-model]] · drill ict-course Stage 7
  - Model 2022 OTE + CSD → [[concepts/entry-models/model-2022-ote]] · drill **D4-d**
  - Daily-bias prerequisite filter → [[concepts/entry-models/daily-bias-model]] · drill **D3-d**
  - SMT-confirmation entry (Layer-2 stack made executable) → [[concepts/entry-models/smt-confirmation-entry]] · drill **D5-b**
  - *(Structure deviations two-set targeting → ict-course **D4-c**.)*
- **U3.3 HTF→LTF cascade + stop/target discipline** → [[concepts/aura/htf-ltf-application]] · drill aura
  **D3-a** (write confirm **and** invalidate before every entry). Stops/targets are canonical per entry-model YAML.
- **Stage gate:** you can run a full **framing → entry → stop → target** plan end-to-end via the
  [[concepts/mastery/unified/README]] one-glance decision flow (and [[concepts/mastery/aura/checklist]]);
  entry models reach **Can-mark → Backtested**.

Ruling **R5**: the **R-multiple blueprint** is canonical; the fixed-dollar cap is its prop-account
expression. Canonical numbers live on the risk page — not restated here.

- **Concepts** → [[concepts/aura/risk-management]] (1–2% per trade · 2–3R daily stop · 10R circuit-breaker ·

## Stage U5 — Frontier confluence-stacking  · extends Layers 2–3  *(LATER — gated on U1–U4)*

The [[concepts/advanced/README|frontier content]] slots in **here, deliberately last**, because every
frontier concept is an *extra independent filter* on a setup you can already read (U1), confirm (U2), and
execute (U3). It drills from macro to micro along **four independent axes** — that independence is what makes
stacking them non-redundant.

> **⚠ Study-and-watch, never trade-live-on (for EMERGING/SPECULATIVE).** Each frontier concept keeps the
> **exact TIER + label** from its source page. The whole stacked confluence is **EMERGING and unbacktested
> here** ([[concepts/advanced/README]] §load-bearing caveat). You may *study, mark, and observe* these in
> replay/live to train the eye, but you may **not** move to live capital on them — the
> [[concepts/mastery/README|Readiness-to-Live Gate]] governs that, and backtesting the stack is a **separate
> workstream (out of scope here)**.

| Axis | Frontier concept (label) | What it adds | Practice (overlay on existing drills — see gap note) |
|---|---|---|---|
| **WHERE** | IPDA 20/40/60-day ranges — windows + trading-day count **ESTABLISHED (Tier 1)**; 20→40→60 ranking **Tier-3 UNVERIFIED**; IRL/ERL **ESTABLISHED**; "liquidity matrix" **SPECULATIVE** → [[concepts/advanced/ipda-data-ranges]] | ranked liquidity targets by algorithmic reach | overlay on the liquidity-marking discipline of ict-course **D1-a** / aura **D1-c** — mark 20/40/60 highs-lows, treat the nearest draw as active (ranking unproven) |
| **WHERE** | CBDR / Asian range / flout + SD projections — CBDR/flout/**Asian-range hours (20:00–00:00 ET)** **ESTABLISHED (Tier 1)**; canonical SD multiples **EMERGING** → [[concepts/advanced/cbdr-and-sd-projections]] | bounded target *zones* (SD ≠ Fibonacci ≠ statistical std-dev) | overlay on ict-course **D3-c** (deviations) — project SD levels, measure on **bodies** (ICT), apply the CBDR <40-pip *equivalent* validity filter (**index-futures point calibration remains an open gap**) |
| **WHEN (ICT)** | ICT Macros + killzone micro-structure / Judas swing + **Silver Bullet windows + mechanics — ESTABLISHED (Tier 1)** (ICT's own 2023 video; 1–3-min MSS + 1:3 R:R stay Tier-3); macro table community-reconstructed (Tier 2–3) → [[concepts/advanced/ict-macros-and-silver-bullet]] | intra-killzone micro-timing of the manipulation→MSS→FVG entry | overlay on ict-course **D3-b** (kill zones) — time *attention* to macro sub-windows; run Silver Bullet's FVG-retracement rule inside its set hour |
| **WHEN (independent)** | Quarterly Theory / 90-min cycles — **EMERGING** (Trader Daye, **not ICT**); daily 6-hr/90-min level best-corroborated → [[concepts/advanced/quarterly-theory]] | fixed non-discretionary boundaries for each PO3 phase (Q2 = manipulation) | overlay on ict-course **D3-a** (PO3/AMD) — mark daily quarters; watch whether a Q2 window lands inside a killzone |
| **DIRECTION** | Midnight Open (00:00 ET) bias — **ESTABLISHED**; "beginning of true day" **Tier 1** (provenance-caveated), bias-pivot wording Tier 2; NDOG as a fillable target → [[concepts/advanced/quarterly-theory]] §True Day Open · [[concepts/business-logic/ict-liquidity]] | daily-bias pivot (price above/below midnight open) | overlay on ict-course **D3-d** (daily bias) — add the midnight-open lean; keep NDOG a discrete target, not a bias rule |
| **CONFIRM** | SMT (NQ/ES/YM) — the U2 nested stack (the only real-time falsifiable leg) | gates all of the above | **U2 itself** — no new drill; the frontier filters are worthless without it |

- **How the stack reads (from [[concepts/advanced/README]] §confluence stack):** a setup earns high
  conviction only when a **WHERE** (IPDA/CBDR target) + a **WHEN** (killzone/macro *and* a Quarterly-Theory
  Q2 agreeing) + a **DIRECTION** (midnight-open bias) + a **CONFIRM** (U2 SMT non-confirmation) all line up.
  **1-of-4 or 2-of-4 = no trade.** The edge is the stack, not any single filter.
- **Drill-library gap (flagged, not forked):** the frontier pages ship **no dedicated exercise library** of
  their own. Until one exists, frontier practice is **study-and-mark observation reps layered on the existing
  session/liquidity drills above** — read the frontier page, mark its structure in replay, and record whether
  it *agreed with* a U1–U3 setup. Authoring dedicated frontier drills (e.g. a Silver-Bullet-hour replay drill,
  an IPDA-target-marking rep set) is a **future gap**, deliberately not invented in this session.
- **Exit bar:** frontier concepts reach **Learned → Can-mark (observation only)**. They do **not** advance to
  Backtested/Live-ready in this workstream — that is gated behind the separate backtesting workstream.

## Stage U6 — The readiness arc (backtest → live → journal)  *(by reference; backtesting out of scope here)*

The ladder's upper stages (**Backtested**, **Live-ready**) and the journaling habit are already sequenced in
both per-track paths. The unified path **references** them rather than re-authoring — and per the
2026-07-17 tracker amendment, **backtesting is a separate workstream, out of scope for this layer**:

- **Backtest in replay** → [[concepts/mastery/aura/learning-path]] Stage 4 (worked-review replay dates) ·
  [[concepts/mastery/ict-course/exercises]] Stage 6 (tape-reading corpus) + Stage 7 (per-model backtest).
- **Live tape reading** → aura Stage 5 · ict-course Stage 6 (T-14 blind live-read).
- **Journal-driven refinement (continuous)** → aura Stage 6 (`D6-a/b/c`) · ict-course Stage 8 (`J-a/b/c`);
  both map to the planned `missed_trades` surface in [[concepts/architecture/trade-schema]].
- **The finish line:** run the full [[concepts/mastery/README]] **Readiness-to-Live Gate**. Only when every
  box there is honestly checked do you move to live capital — and even then, **start small**.

## One-glance stage map

```
U0 Psychology & discipline  ──►  U1 Structural primitives  ──►  U2 Nested SMT stack ⭐
        (held habit)                (5 primitives Can-mark)         (Seq + triad SMT Can-mark)
                                                                             │
        U6 Readiness arc  ◄── U5 Frontier stacking ◄── U4 Risk ◄── U3 Execution
       (backtest/live/gate)   (study-and-watch only)   (R blueprint)  (time→entry→levels)
```

Each arrow is a **gate**: do not open the next stage until the current stage's exit bar is met. Frontier (U5)
is reachable only after U1–U4 — it stacks filters onto a setup you can already read, confirm, and execute.
