# Advanced / Frontier ICT — Hub

Deep, less-common ICT concepts researched in Phase 3 (2026-07-17) to extend the mastery layer **beyond**
the two ingested mentor corpora. These are the "frontier" pages: high-impact ideas from the wider ICT body
of knowledge that materially sharpen the [[concepts/mastery/unified/README|Unified Playbook]]'s execution
and confirmation layers, but that neither MrWitness-AXL nor dOoMeR taught in the captured material.

> **This content is web-sourced and vetted, not corpus-sourced.** Every page carries a source **tier** and
> a **confidence label**. Read the labels — the whole point of this hub is that ICT's open-web footprint is
> mostly marketing noise, and these pages separate the signal from it rather than adding to the pile.

## The cross-cutting confluence stack ⭐

The single highest-value synthesis of the whole research pass: the frontier concepts drill from macro to
micro along **independent axes**, which is exactly what makes stacking them non-redundant. Each answers a
*different* question, so their agreement is real evidence rather than the same observation repeated.

| Layer | Concept | Answers | Source |
|---|---|---|---|
| Target | IPDA 20/40/60-day ranges | **WHERE** — ranked liquidity targets by algorithmic reach | [[concepts/advanced/ipda-data-ranges]] |
| Time (macro) | Quarterly Theory Q2 / 90-min sub-cycles | **WHEN** (independently derived) | [[concepts/advanced/quarterly-theory]] |
| Time (ICT) | Killzones + Macros | **WHEN** (ICT's own, roughly corroborates) | [[concepts/advanced/ict-macros-and-silver-bullet]] |
| Bias | Midnight Open / draw on liquidity | **DIRECTION** | [[concepts/advanced/quarterly-theory]] · [[concepts/business-logic/ict-liquidity]] |
| Confirmation | SMT (NQ/ES/YM) — the nested stack | **CONFIRM** (the only real-time falsifiable signal) | [[concepts/mastery/unified/README]] Layer 2 |

**How to read it:** an intraday setup earns high conviction only when a **WHERE** (an IPDA/CBDR target), a
**WHEN** (a killzone/macro *and* a Quarterly-Theory Q2 window agreeing), a **DIRECTION** (midnight-open bias),
and a **CONFIRM** (SMT non-confirmation across the triad) all line up. 1-of-4 or 2-of-4 = no-trade. This is
how the frontier content plugs into [[concepts/mastery/unified/README]] Layer 3 (execution) — as extra,
independent filters on *when* and *where*, gated by the Layer-2 SMT confirmation.
